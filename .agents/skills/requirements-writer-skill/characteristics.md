# Characteristics

## C1 Necessary
Requirement is essential.
Question: If removed, is capability lost?

## C2 Appropriate
Requirement belongs to correct architecture level.

## C3 Unambiguous
One interpretation only.

## C4 Complete
Contains what, how well and conditions.

## C5 Singular
One obligation.

## C6 Feasible
Achievable within constraints.

## C7 Verifiable
Pass/fail objectively determinable.

## C8 Correct
Accurately represents source intent.

## C9 Conforming
Respects defined patterns and style.

## C10 Complete Set
No necessary requirements missing.

## C11 Consistent Set
No conflicts or duplicates.

## C12 Feasible Set
Requirements can coexist.

## C13 Comprehensible Set
Understandable by stakeholders.

## C14 Able To Be Validated
Supports proving intended-use satisfaction.
