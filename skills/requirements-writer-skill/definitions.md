# Definitions

Entity: item to which a need or requirement applies.
Need: stakeholder expectation expressed from stakeholder perspective.
Requirement: formal obligation expressed using SHALL.
Requirement Set: structured collection of requirements.
Verification: demonstrate requirement satisfaction by inspection, analysis, demonstration or test.
Validation: demonstrate needs and intended use are satisfied.
Traceability: relationship between source, need and requirement.
Allocation: assignment of responsibility to lower-level entities.
Design Input: WHAT is needed.
Design Output: HOW design implements it.
