# Examples

BAD: The system shall respond quickly.
WHY: vague.
GOOD: The System shall display Search_Results within 2 seconds.

BAD: The user shall be able to create reports.
WHY: requirement placed on user.
GOOD: The Reporting_System shall allow the User to create Reports.

BAD: The system shall never fail.
WHY: absolute.
GOOD: The System shall achieve Availability greater than or equal to 99.5%.

BAD: The system shall store and display and transmit data.
WHY: multiple obligations.
GOOD:
The System shall store Data.
The System shall display Data.
The System shall transmit Data.
